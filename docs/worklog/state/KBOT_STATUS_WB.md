# Aplicații web — intervenții comune

## SLICE-WB02-01 — Certificat digital Administrator — 30.10.2026

**IMPLEMENTAT_LOCAL, NERULAT, NEPUBLICAT.** Din meniurile VERCON, ADECHIT și portal, Administratorul unității curente poate deschide pagina dedicată de înrolare a certificatului personal, cu verificarea rolului la fiecare apel și reutilizarea înrolării mTLS din portal.

[Worklog, fișiere și limite](../SLICE-WB02-01-certificat-digital-administrator.md). Ajutorul VERCON/ADECHIT și ghidul ADECHIT includ noua opțiune. Fără teste, verificări automate, browser, HTTP, SQL sau publicare. Rămân neprobate funcțional și vizual înrolarea cu token real, refuzurile pentru alte roluri/sesiune expirată și revenirea în aplicație. Publicarea și probele pe server aparțin utilizatorului.
