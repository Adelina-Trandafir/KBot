Cum lucrăm

După modificări HTML, CSS sau JavaScript, reîncarcă pagina. După modificări Python, repornește serverul. Regenerarea raportului preia noua machetă; un PDF deja deschis păstrează versiunea cu care a fost generat.

La repornire, modificările datelor demo se pierd. Serverul nu se conectează la MariaDB, nu trimite e-mailuri și nu folosește conturi reale.

Acest preview acoperă Lista de alimente și raportul ei. Salvările demonstrative nu validează stocurile, tranzacțiile MariaDB, drepturile sau blocarea simultană din aplicația reală.
